# xiaohongshu-mcp v1.0.0

这是 **liaogx/xiaohongshu-mcp 的首个正式发行版**，从 `1.0.0` 独立编号，并不表示上游版本回退。基于 [xpzouying/xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp) 修改，继续使用 Apache License 2.0，保留原作者来源声明。与小红书官方无隶属关系。

## 1. 更新内容

### 小红书与 RedNote 双站兼容

- 同一套程序支持 `www.xiaohongshu.com` 与 `www.rednote.com`，默认 `XHS_SITE=auto`。
- 保存实际扫码落地站点，适配海外手机号登录后的域名跳转；不改写 Cookie 域名，不混用两个站点的访问令牌。
- 登录、搜索、筛选、推荐、详情、公开主页、通知、评论回复、点赞收藏、图文/视频发布及现有清理操作统一使用当前站点路由。

### 稳定性和操作确认

- 修复隐藏的同名筛选项误选、主页列表尚未加载就报空等问题。
- 区分登录失效、安全验证、页面读取失败，避免统一误报为搜索超时。
- 登录状态原子保存；提供人工扫码/安全验证恢复工具，未确认成功时保留原会话。
- 评论等操作保留业务响应核验、重复发送保护与本地回执；结果不确定时不声称成功。
- 账号清理使用计划、预览、明确确认和单条执行，保留账号身份与笔记所有权检查。

### 发行与工具

- 提供三种系统、三类工具共 9 个预编译文件，使用时无需安装 Go。
- 新增 `-version`，输出版本、提交、Go、构建时间和平台；MCP 连接信息与健康检查不再显示固定旧版本号。
- 附带 SHA256 校验、机器可读构建信息及许可证文本；补充版本一致性和发行构建测试。
- 通用图片下载与本地浏览索引脚本继续随源码提供，使用方法见[图片下载说明](https://github.com/liaogx/xiaohongshu-mcp/blob/v1.0.0/docs/DOWNLOAD_IMAGES.md)。

## 3. 使用方法

### macOS Apple Silicon

把主程序、登录工具和按需下载的恢复工具放到自己创建的运行文件夹。在终端进入该文件夹后执行；本段使用当前文件夹保存登录状态，**同一账号的各工具要使用同一个文件**。

```bash
chmod +x ./xiaohongshu-mcp-darwin-arm64 ./xiaohongshu-login-darwin-arm64
export COOKIES_PATH="$PWD/cookies.json"
export XHS_SITE=auto

# 查看版本，不启动浏览器
./xiaohongshu-mcp-darwin-arm64 -version

# 首次运行会下载浏览器，然后打开专用窗口，使用 App 扫码
./xiaohongshu-login-darwin-arm64

# 登录成功后，在同一个终端启动后台浏览器模式的服务
./xiaohongshu-mcp-darwin-arm64 -port=127.0.0.1:18060
```

主程序会持续占用当前终端，`Ctrl+C` 停止；“后台浏览器”不等于自动安装系统后台服务。再次打开终端时，需要重新设置相同的环境变量。

### Linux x64

在图形桌面环境运行登录/恢复工具；纯服务器需要自己配置可交互的图形会话，不会由程序自动建立远程桌面。浏览器还需要 Chromium 的系统动态库和字体，容器示例见 [Docker 指南](https://github.com/liaogx/xiaohongshu-mcp/blob/v1.0.0/docker/README.md)。

```bash
chmod +x ./xiaohongshu-mcp-linux-amd64 ./xiaohongshu-login-linux-amd64
export COOKIES_PATH="$PWD/cookies.json"
export XHS_SITE=auto
./xiaohongshu-login-linux-amd64
./xiaohongshu-mcp-linux-amd64 -port=127.0.0.1:18060
```

### Windows x64（PowerShell）

进入保存下载文件的文件夹：

```powershell
$env:COOKIES_PATH = Join-Path (Get-Location).Path "cookies.json"
$env:XHS_SITE = "auto"
.\xiaohongshu-mcp-windows-amd64.exe -version
.\xiaohongshu-login-windows-amd64.exe
.\xiaohongshu-mcp-windows-amd64.exe -port=127.0.0.1:18060
```

### MCP 接入与服务验证

- 客户端传输类型：**Streamable HTTP**。
- MCP URL：`http://127.0.0.1:18060/mcp`。
- 健康检查：浏览器打开 `http://127.0.0.1:18060/health`，应返回服务状态及 `version: "1.0.0"`。
- 根路径 `/` 没有操作首页，显示 404 不表示启动失败。图形调试可使用 MCP Inspector，它不是本服务自带的运营后台。
- 先调用 `check_login_status`，确认账号与站点，再调用搜索、推荐和详情等工具。健康检查成功不代表小红书已登录。
- MCP 连接面板的 **Version** 是本项目版本；**Protocol** 的日期表示 MCP 协议版本，两者不相同。

支持手工指定 `XHS_SITE=xiaohongshu` 或 `XHS_SITE=rednote`，通常保留 `auto` 即可。显式站点与实际扫码落地站点不匹配时会报错，不会静默替换账号。详见[双站点说明](https://github.com/liaogx/xiaohongshu-mcp/blob/v1.0.0/docs/SITES.md)。

### 人工验证恢复

先暂停正在使用当前会话的任务，然后在使用相同 `COOKIES_PATH`、`XHS_SITE` 和代理的终端中运行：

```bash
# macOS 示例：打开搜索验证页，手动完成平台验证
chmod +x ./xiaohongshu-recover-darwin-arm64
./xiaohongshu-recover-darwin-arm64 -keyword '咖啡'

# 需要重新扫码时，成功前保留已有登录文件
./xiaohongshu-recover-darwin-arm64 -fresh
```

Linux/Windows 替换为对应文件名。恢复后重新检查登录，并做一次只读搜索；工具不会自动完成验证码或保证解除平台限制。

## 4. 注意事项

- **首次启动联网下载浏览器**（约 140–190 MB），校验后缓存到当前系统用户缓存目录。后续复用；下载文件中不包含浏览器。
- 登录信息默认依当前运行目录查找；以上例子用 `COOKIES_PATH` 固定位置。运行文件夹不要放进公开仓库；不要分享登录文件或真实二维码。
- 默认浏览器模式为无头，可用 `-headless=false` 调试；扫码与安全验证需要人工完成。
- 示例仅监听本机。程序省略 `-port` 时原有默认是 `:18060`（所有网卡），不要把未鉴权服务暴露到公网；需要远程接入时另行配置鉴权和网络保护。
- 一个实例只管理一份当前账号会话；双域名支持不等于同时登录多个账号。多实例需隔离端口、登录文件和状态目录。
- macOS 文件未进行 Apple 开发者签名/公证，Windows 文件未进行 Authenticode 签名。可能出现系统安全提示；先核对来源和 SHA256，不要全局关闭系统安全保护。
- 图文/视频发布、评论、回复等受平台权限、审核、限流和安全验证影响；“已登录”不保证所有功能随时可用，不承诺百分之百成功。
- 清理工具只处理可枚举、可核实的条目；完整历史评论、全部关注列表可能无法获取，群聊退出和私信清空仍需手机端处理。详见[清理能力边界](https://github.com/liaogx/xiaohongshu-mcp/blob/v1.0.0/docs/ACCOUNT_CLEANUP.md)。
- **验证范围：**离线 Go/Python 测试、合成页面浏览器回归、版本一致性测试；Mac Apple Silicon 上已有 RedNote 核心流程实测。Windows/Linux 附件为交叉编译并检查格式与构建信息，未声称在对应系统完成真实账号测试。本次发行不执行公开互动。

## 6. Assets 与文件校验

除上述 9 个可执行文件外，另提供：

| 附件 | 用途 |
| --- | --- |
| `SHA256SUMS` | 校验下载内容是否完整、是否与发行附件一致 |
| `BUILD-INFO.json` | 可机器读取的版本与构建清单 |
| `LICENSE` | 项目 Apache License 2.0 全文 |
| `NOTICE` | 上游来源与修改声明 |
| `THIRD_PARTY_NOTICES.txt` | Go 及第三方依赖的许可文本 |
| `Source code (zip / tar.gz)` | GitHub 自动生成的 tag 源码包，不包含可运行程序 |

将 `SHA256SUMS` 放在下载文件旁边。只下载当前系统的文件时，可逐个计算哈希并与清单中的同名文件对照：

```bash
# macOS
shasum -a 256 ./xiaohongshu-mcp-darwin-arm64
# Linux
sha256sum ./xiaohongshu-mcp-linux-amd64
```

```powershell
# Windows PowerShell
Get-FileHash .\xiaohongshu-mcp-windows-amd64.exe -Algorithm SHA256
```

SHA256 用于一致性校验，不代替发布者数字签名。后续修复会发布新版本，不覆盖此版本的下载文件。
